Device marketing names In review

A data pipeline transformation that turns Apple model identifiers like iPhone15,2 into the names people recognise, sourced from Xcode's device database. Simulators are only labelled when the SDK says so, because native Mac apps report the same CPU architecture. Covered by unit tests and nine end-to-end cases.

disableGeoIp for the iOS SDK Merged

Lets apps opt out of IP-based location on both events and feature flags, matching PostHog's other SDKs.

Deep link test isolation Merged

Flaky deep link tests were failing iOS SDK CI across the repo. Each test now gets its own event storage, so one test's events can't leak into another's assertions.
